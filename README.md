# Olá, sou o Reulyson 👋

Desenvolvedor backend com Python, de Manaus (AM). Trabalho principalmente com FastAPI, Django e Flask, construindo APIs REST, regras de negócio no servidor e integrações entre sistemas, com PostgreSQL, Redis e Docker no dia a dia. No frontend, uso React com TypeScript quando o projeto pede.

Ao longo da minha trajetória no Grupo Rede Amazônica, participei da migração de um sistema legado em Java para Python, construí plataformas que substituíram processos manuais por fluxos com validação, aprovação e auditoria, e desenvolvi um motor de cálculo de comissões e metas comerciais. Sou formado em Engenharia de Controle e Automação.
